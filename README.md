# ارسی — وب‌سایت رستوران و چای‌خانهٔ سنتی ایرانی

نسخهٔ نخست طراحی و پیاده‌سازی؛ کاملاً راست‌به‌چاپ، بدون هیچ وابستگی بیرونی (فونت‌ها، تصویرها و الگوها همه میزبانی محلی‌اند).

## اجرا

```bash
python3 -m http.server 8080 --bind 0.0.0.0 -d .
# سپس: http://localhost:8080
```

## ساختار

```
index.html            کل صفحهٔ تک‌برگه (هیرو، حکایت، منو، فضاها، چای‌خانه، رزرو، پابرگ)
css/style.css         همهٔ سبک‌ها؛ متغیرهای رنگ در :root بالا
js/main.js            سربرگ چسبان، منوی موبایل، ظهور تدریجی، پالایش منو، اعتبارسنجی فرم رزرو
assets/fonts/         وزیرمتن و Markazi Text (زیرمجموعهٔ فارسی، woff2، پروانهٔ OFL)
assets/img/           تصویرهای بهینه‌شدهٔ webp + نشان‌ها و الگوهای svg
_raw/                 خروجی خام تصویرساز (جای عکس‌های واقعی رستوران)
_tools/               فیلم‌نامه‌های ساخت: فونت‌ها، برش پس‌زمینهٔ بشقاب‌ها، نشان نستعلیق
```

## نقطه‌های تغییرِ سریع

- **رنگ‌ها و فونت‌ها:** بلوک `:root` در `css/style.css`.
- **نام، تلفن، نشانی، ساعات:** در `index.html` جست‌وجو کنید: «ارسی»، `tel:`، «عودلاجان».
- **غذاها و قیمت‌ها:** کارت‌های `<article class="dish">` در بخش `#menu` (برچسب `data-cat` دستهٔ پالایش را تعیین می‌کند).
- **تصویرها:** فایل‌های `assets/img/` را با عکس‌های واقعی هم‌نام جایگزین کنید؛ برش بشقاب‌ها با `_tools/build_images.py` بازسازی می‌شود.
- **نشان نستعلیق و بیت هیرو:** `_tools/build_logo.py` (متن را در انتهای فایل عوض کنید).

## یادداشت‌ها

- تصویرهای کنونی نمونهٔ تولیدشده با هوش مصنوعی‌اند و باید با عکس‌های واقعی خانه جایگزین شوند.
- فرم رزرو نمایشی است و چیزی ارسال نمی‌کند؛ برای اتصال واقعی، `js/main.js` (تابع submit) را به سرویس دلخواه وصل کنید.
- فونت‌ها بر پایهٔ پروانهٔ SIL OFL 1.1 (وزیرمتن، Markazi Text، Noto Nastaliq Urdu) زیرمجموعه‌گیری شده‌اند؛ متن پروانه‌ها در `_tools/fonts/OFL-*.txt`.
